# 股票列表与 K 线详情设计

日期：2026-09-27  
状态：待需求方审阅  
范围：将前端首页从选股信号表调整为股票列表与单只股票日 K 线详情。

## 背景

当前后端已有本地股票名称查询 `GET /api/market/{symbol}/basic` 和本地日线查询 `GET /api/market/{symbol}/ohlcv`。日线响应包含日期、开盘价、最高价、最低价、收盘价、成交量和成交额，按日期升序返回，最多 500 根。前端首页目前是选股信号看板，没有股票列表和图表。

用户确认的目标流程是：显示全部 A 股，搜索或分页浏览，点击一只股票后在当前页查看其 K 线图。

## 目标

- 首屏展示 `stock_basic` 中的全部本地股票代码和名称。
- 支持按代码或名称搜索，并使用服务端分页。
- 点击列表项后，在同一页面详情区展示该股本地日线蜡烛图及成交量。
- 默认展示最近 250 根日线，并提供 60、120、250、500 根范围切换。
- 在桌面端并排显示列表和详情；窄屏下列表在上、详情在下。
- 沿用现有 session/API Key 鉴权与同源 API 请求方式。
- 保留后端信号查询、跑批和调度能力；首页不再显示信号表。

## 非目标

- 不增加分钟线、周线、复权方式切换、均线或其他技术指标。
- 不触发在线行情拉取；列表和图表只读本地 SQLite。
- 不增加跑批控制、任务历史或仪表盘页面。
- 不删除现有信号 API、策略执行、任务存储或飞书推送能力。
- 不在股票列表中逐只计算或查询最新行情价格。

## 后端设计

### 股票列表接口

新增鉴权接口：

```http
GET /api/market/stocks?keyword={keyword}&limit=50&offset=0
```

响应：

```json
{
  "items": [
    { "symbol": "000001", "name": "平安银行" }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```

- 数据来自行情库 `stock_basic`，不联网。
- `keyword` 可选，去除首尾空格后按股票代码或名称进行子串匹配。
- `limit` 默认 50，允许范围 1–200；`offset` 默认 0，必须大于等于 0。
- 排序固定按 `symbol` 升序，保证翻页稳定。
- 查询使用参数化 SQL 和只读 SQLite 连接；名称/代码搜索使用同一关键词。
- 空关键词表示不筛选。
- 股票基础表尚未同步时，返回结构化 `409 stock_list_not_seeded`，提示运行 `python main.py --names` 或 `python main.py --backfill`。已初始化但搜索无匹配项时返回 200 和空 `items`。

### 日线接口

复用现有 `GET /api/market/{symbol}/ohlcv?limit=N`，不新增行情写入路径。前端把所选范围作为 `limit` 传入，范围选项只允许 60、120、250、500。接口继续返回日期升序的 OHLCV 数据。

现有单股基础信息和信号接口保持不变。股票列表路由与 `/api/market/{symbol}/ohlcv` 路由路径不同，不冲突。

## 前端设计

### 页面状态

- 首页替换当前信号表，分为股票列表区、股票详情区。
- 列表显示代码和名称；搜索框按输入关键词查询，搜索变化时回到第一页。
- 每页默认 50 条，使用服务端总数显示分页。
- 点击某一股票后记录选中代码并请求日线；未选择时详情区显示操作提示。
- 切换 K 线范围时只重新请求已选股票的日线，不重置股票列表分页。
- 翻页或搜索时保留当前已选股票详情，详情标题始终显示当前选中代码和名称。
- 桌面宽度采用列表与详情并排布局；窄屏采用上下布局。

### K 线图

- 采用 TradingView Lightweight Charts 的蜡烛图与成交量直方图系列，使用同一日期时间轴。
- 价格上涨显示红色，下跌显示绿色，符合 A 股常用配色。
- X 轴显示交易日期，图表随容器宽度变化并在组件卸载时清理实例。
- 显示 60/120/250/500 日线切换，初始为 250。
- 显示 TradingView 图表署名，符合该图表库的署名要求。

### 加载与异常状态

- 列表加载、股票列表未初始化、搜索无结果、列表接口失败分别显示明确状态。
- 股票详情未选中、K 线加载中、该股无本地日线、K 线接口失败分别显示明确状态。
- 行情库尚未回填的既有 `database_not_seeded` 响应继续显示回填提示。
- 401 仍由现有 API client 跳转登录页；页面不存储 API Key。

## 数据流

```text
浏览器加载首页
  └─ GET /api/market/stocks?keyword=&limit=50&offset=0
       └─ 只读 stock_basic → 股票代码、名称及总数

用户点击股票 / 调整日线范围
  └─ GET /api/market/{symbol}/ohlcv?limit={60|120|250|500}
       └─ 只读 stock_daily → 升序 OHLCV → 蜡烛图与成交量柱
```

## 验收标准

1. 列表接口默认按代码排序返回 50 条及准确总数；`limit` 和 `offset` 生效。
2. 代码和名称关键词都能正确筛选，空结果返回 200 和空数组。
3. 股票列表数据来自 `stock_basic`，查询只读且不联网；列表未同步时能给出同步说明。
4. 前端首次加载显示股票列表，搜索、分页能更新列表且不会一次加载全部股票。
5. 点击股票展示该股代码、名称、蜡烛日 K 线和成交量；默认 250 根。
6. 60、120、250、500 范围选择会请求对应数量的本地日线；无数据、加载失败和未回填状态有明确文案。
7. 桌面和窄屏布局均可使用；图表在容器变化时调整尺寸，切换股票/卸载时不残留旧图表实例。
8. session/API Key 鉴权继续有效；前端 API Key 不进入持久化浏览器存储。
9. 后端信号接口、任务跑批和调度功能保留；静态构建仍由 FastAPI 同源托管。
10. 前端生产构建和后端相关自动化检查通过。
